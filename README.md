# QR Menu

Сервис цифрового QR-меню для кафе и ресторанов.

## Что уже есть

- публичное меню по адресу `/r/:slug`;
- поиск и категории;
- PostgreSQL для заведений, категорий и блюд;
- защищённая админка `/admin`;
- создание нескольких заведений;
- добавление категорий и блюд;
- скрытие/показ блюд;
- отдельная ссылка на меню каждого заведения;
- автоматический PNG QR-код `/api/restaurants/:slug/qr`;
- мобильный интерфейс.

## Запуск

```bash
npm install
npm start
```

Без `DATABASE_URL` работает демонстрационное меню `/r/demo`. Для админки и сохранения данных нужен PostgreSQL.

## Переменные окружения

- `DATABASE_URL` — строка подключения PostgreSQL;
- `ADMIN_PASSWORD` — пароль админки;
- `PUBLIC_BASE_URL` — публичный адрес сайта, например `https://example.up.railway.app`;
- `PORT` — задаётся Railway автоматически.

## Railway

1. Deploy from GitHub repo.
2. Добавить PostgreSQL в тот же Railway project.
3. Убедиться, что `DATABASE_URL` доступна сервису приложения.
4. Добавить `ADMIN_PASSWORD`.
5. После получения публичного домена добавить `PUBLIC_BASE_URL`.
6. Start command: `npm start`.

После первого запуска таблицы и демонстрационное меню создаются автоматически.
